# QR Toolkit User Guide

## Overview

QR Toolkit is an all-in-one QR Code platform that lets you create, customize, scan, validate, and manage QR codes securely. Everything runs locally inside your browser, keeping your data private.

---

# Getting Started

Using the application only requires four simple steps.

## Step 1 — Select QR Type

Choose the type of QR code you want to generate.

Supported types include:

- Website URL
- Wi-Fi Network
- Contact Card (vCard)
- Plain Text
- Email
- Phone Call
- SMS
- Location
- Calendar Event
- Crypto Payment

---

## Step 2 — Enter Content

Fill in the required information.

Examples:

### Website

Enter

https://example.com

The application automatically formats the URL if needed.

### Wi-Fi

Enter

- Network Name (SSID)
- Password
- Encryption Type

Users can connect by simply scanning the QR code.

### Contact Card

Provide

- Name
- Company
- Job Title
- Phone
- Email
- Website

The QR will save the contact directly into the user's phone.

### Email

Fill

- Recipient
- Subject
- Message

Opening the QR launches the default email app.

### Phone

Enter a valid phone number.

Scanning immediately opens the dialer.

### SMS

Enter

- Phone Number
- Message

Scanning opens the messaging application with the message pre-filled.

### Location

Provide either

- Latitude & Longitude

or

- Place Name

Scanning opens the location in Google Maps.

### Calendar Event

Configure

- Event Name
- Date
- Time
- Location

The QR creates a calendar event.

### Crypto

Supported

- Bitcoin
- Ethereum
- Solana
- USDT
- Dogecoin

Optionally include

- Amount
- Payment Label

# Step 3 — Customize QR

- Foreground Color
- Background Color
- Transparent Background
- Gradient

## Eye Pattern

Choose between

- Square
- Rounded
- Circle
- Leaf

## Error Correction

Available levels

L

M

Q

H

Higher correction allows better recovery when the QR is partially damaged.

## Logo Overlay

Insert

- Wi-Fi
- Email
- Phone
- Bitcoin
- User
- Custom Logo

## Call-To-Action

Add custom text such as

- Scan Me
- Join Wi-Fi
- Visit Website
- Download App

# Step 4 — Preview

The QR Preview updates automatically whenever you change data or styling.

The application also checks

- Color Contrast
- Scan Readability
- Error Correction

Warnings appear if the QR may become difficult to scan.

# Safety Check

Before using a QR code, Safety Check verifies

- Suspicious URLs
- Malformed Data
- Dangerous Redirects
- Invalid QR Structure

Potential risks are highlighted before opening the content.

---

# Privacy

QR Toolkit is designed with privacy first.

- Client-side processing
- No cloud uploads
- No user tracking
- Local storage only
- Secure QR generation

---

# Tips

✔ Use high contrast colors.

✔ Avoid very small QR sizes.

✔ Keep enough white margin around the QR.

✔ Use SVG for printing.

✔ Use Error Correction Level H when adding a logo.

✔ Test your QR before sharing.
